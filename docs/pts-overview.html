Publication Trust Score

PTS — Two-Score Framework

An evidence-based tool that assesses a single publication on two independent 100-point scores: PTS-A (Antisemitism, IHRA) and PTS-J (Journalistic Standards, IMPRESS). A model returns per-criterion judgements with exact quotes; a deterministic scorer verifies every quote and applies the rules. The two scores are never blended.

PTS-A · IHRA · AS1–AS6 PTS-J · IMPRESS · J1–J11 + JD Deterministic scorer Quote verification Stance gate Human-review routing

How it works

Give the app an article by URL or pasted text. It extracts the publication into labelled sections (HEADLINE, STANDFIRST, BYLINE, PUBLISHED, SOURCE, BODY), sends it to a model with a forced, structured tool call, then runs a deterministic scorer that verifies every piece of evidence and computes both numbers. The model never computes the score — software does.

Providers, in order: OpenRouter (if OPENROUTER_API_KEY is set; default anthropic/claude-haiku-4.5) → Anthropic (if ANTHROPIC_API_KEY is set; default claude-haiku-4-5) → Mock (labelled all-PASS, no key needed).

Cross-cutting scoring rules

Evidence verification

Every FAIL needs an exact quote, checked against the text with tolerant matching (whitespace / curly-quote normalisation, ellipsis splitting, label stripping, approximate match ≥ 0.85). No verifiable quote → no deduction; the finding is rejected and queued for review.

Stance gate (PTS-A only)

AS1–AS5 can fail only for OWN_VOICE or UNCRITICAL_AMPLIFICATION. REPORTED_CONTEXTUALISED / COUNTERED content is not penalised. A FAIL with failure_stance: NONE inherits overall_stance.

Critical caps (39)

AS1 or AS4 failing in the publication's own voice caps PTS-A at 39. Fabrication (J1, or a fabricated source under conduct clause 8) caps PTS-J at 39.

NOT_ASSESSABLE & rescaling

Unassessable criteria leave the "possible" total and the score is rescaled to 100 — so coverage can be below 100 while the score is 100. The absence of a problem is a PASS, not NOT_ASSESSABLE.

Human-review routing

AS1, AS4, AS5 failures; any model-flagged review; and any accepted failure with confidence < 0.5 are routed to a de-duplicated review queue (per score).

Legal flag

A separate routing flag (INCITEMENT / HOLOCAUST_DENIAL) — never a legal finding, and never part of either score.

Designation profiles & tier bands

Designations

  • ARTICLE / DOCUMENTARY — all AS + all J + JD.
  • POST — PTS-A in full; PTS-J only on J1, J2, J5 + JD.
  • SATIRE — labelled, not scored (both scores null).

Tier bands

PTS-A: ≥100 No indicators · ≥75 Minor concerns · ≥60 Amplification/contested · ≥40 Antisemitic content present · else Severe.

PTS-J: ≥100 Compliant · ≥75 Generally compliant · ≥60 Compliant with exceptions · ≥40 Breach · else Serious breach.

Scope & limitations

These scores judge the text as written. They detect antisemitism (IHRA) and journalistic-standards breaches (IMPRESS) that are visible in the piece itself, including how claims are attributed.

They are not a fact-check of claims against external reality, and not a bias, balance or one-sidedness meter. Properly attributed, reported content (a REPORTED_CONTEXTUALISED stance) is expected to score high even on the most contested topics — that is the stance gate working as designed, not leniency.

Provenance & reproducibility

Every result carries provenance: the run ID, model, prompt version, a SHA-256 of the input text, and a UTC timestamp. The deterministic scorer ships with an 8-scenario self-test (npm run selftest), an offline demo (npm run demo:bad), and a live endpoint test (npm run test:endpoint).
